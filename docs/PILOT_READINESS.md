## Условия ТЗ §12

| Условие | Статус |
|---|---|
| Все пять ролей выполняют основные операции | E2E на смартфоне (локально); на staging — после SMTP и приглашений |
| Разграничение доступа протестировано | pgTAP (в т. ч. инварианты `120_security`), интеграционные, E2E, smoke staging |
| Заявки, приёмки, выдачи и возвраты согласованы | фазы 2–3; подтверждается сверкой на реальных документах |
| Остатки и долги совпадают с контрольными данными | сверочные функции и отчёты; сверка с бухгалтером — по сценарию |
| Частичные оплаты | поставщикам и бригадам |
| Утверждённые акты неизменяемы | триггеры + тесты |
| Повторные запросы не дублируют операции | idempotency keys + тесты |
| Аудит | да |
| Восстановление резервной копии проверено | локально — да (протокол); staging — после пароля БД и `BACKUP_PASSPHRASE`; ручное с Auth — до пилота |
